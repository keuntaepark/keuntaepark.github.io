Wildfire Spread Predictor

← Back to Portfolio

Problem

Existing forecast systems are rendered ineffective during the critical "Golden Time" of a wildfire response. Obsessed with achieving a perfect prediction by modeling all variables, they are too slow to be actionable when it matters most. This creates a paradox: the pursuit of a perfect forecast prevents a fast, effective response.

Action

  • Pivoted product strategy from 'Perfect prediction' to 'Rapid response support', establishing 'time-to-forecast' as the North Star Metric to align team priorities.
  • Designed a lightweight ML model prioritizing high-impact, real-time variables (wind, humidity) and fusing pre-trained models for others, striking a strategic balance between speed and accuracy.
  • Conducted EDA on historical data, revealing wind speed accounted for ~70% of spread variance, validating the model's focus.
  • Introduced a 'Confidence Layer' (±% Uncertainty Score) to quantify forecast reliability, building user trust and enabling data-informed risk assessment.
  • Architected a modular API/Model/UI system to facilitate agile development and rapid, iterative feature deployment.

Result

  • Reduced forecast generation time by 95% (from ~2 hours to < 6 minutes), securing the critical "Golden Time" for initial response.
  • Empowered field commanders with high-velocity, confidence-based decision-making capabilities.
  • Achieved high situational accuracy by weighting real-time variables, leading to better predictions during sudden environmental shifts.
  • Built a scalable foundation prepared for future integration of new data sources (terrain, vegetation) and public APIs.

Tech Stack

The Wildfire Predictor was built by merging historical Korean wildfire data with real-time wind data to forecast spread probability in 8 directions. Core modeling was implemented in Python, with dynamic visualization handled by JavaScript.

Python

  • Data Processing & Analysis:pandas, numpy
  • Machine Learning Modeling: scikit-learn (for Random Forest), xgboost (for performance comparison)
  • Data Output: json

JavaScript

  • Data Visualization:Leaflet.js
  • External Data Collection: Open-Meteo API for real-time wind data
  • Core Logic: A custom function to fuse AI predictions with real-time wind conditions.

문제 정의 (Problem)

산불 대응의 성패를 가르는 '골든 타임'에 기존 예보 시스템은 사실상 무력합니다. 모든 변수를 고려한 완벽한 예측에 집착한 나머지, 예측 시간이 과도하게 소요되어 가장 중요한 초기 대응 시점을 놓치기 때문입니다. 즉, '느리고 완벽한 예측'이 '빠르고 효율적인 대응'을 방해하는 역설이 발생합니다.

나의 기여 (Action)

  • 제품 목표를 '완벽한 예측'에서 '신속 대응 지원'으로 전환, '예측 소요 시간'을 핵심 성공 지표(North Star Metric)로 재설정.
  • 실시간 변수(바람, 습도)에 집중하는 경량화된 ML 모델을 설계, 속도와 정확도의 전략적 균형점을 확보.
  • 과거 데이터 탐색적 분석(EDA)을 통해 바람이 확산 속도 분산의 70% 이상을 설명함을 규명, 모델 설계의 타당성 입증.
  • 예측의 신뢰도를 정량화하는 '불확실성 지표(±%)'를 도입, 사용자의 데이터 기반 의사결정 및 신뢰도 확보.
  • 모듈형 아키텍처(API/모델/UI)를 구축하여, 신속한 기능 배포와 애자일 방식의 반복 개선이 가능한 기술 기반 마련.

성과 및 시사점 (Result)

  • 예측 소요 시간을 평균 2시간에서 6분 이내로 95% 단축하여, 초기 대응을 위한 '골든 타임'을 성공적으로 확보.
  • 현장 지휘관에게 신뢰도 기반의 신속한 의사결정 환경을 제공하여 초기 대응 능력 강화.
  • 실시간 변수 가중치를 높여 돌풍 등 급변하는 기상 상황에 대한 예측 정확도 향상.
  • 향후 지형, 식생 등 신규 데이터 소스 및 공공 API 연동이 용이한 확장 기반 마련.

기술 스택

Wildfire Predictor는 과거 한국 산불 데이터와 실시간 바람 데이터를 융합하여 8방향 확산 확률을 예측하는 프로젝트입니다. 핵심 모델링은 Python으로, 동적인 시각화는 JavaScript로 구현했습니다.

Python

  • 데이터 처리/분석: pandas, numpy
  • 머신러닝 모델링: scikit-learn (Random Forest), xgboost(비교용)
  • 데이터 출력: json

JavaScript

  • 데이터 시각화: Leaflet.js
  • 외부 데이터 수집: Open-Meteo API
  • 핵심 로직: AI 예측과 실시간 바람을 융합하는 동적 가중치 로직

Development Process

ver.01: Core Concept Validation

Problem: Text-based forecasts lacked spatial context.
Action: Built an MVP with a simple fan-chart to test the core hypothesis that map-based visuals would be more effective for field decisions.

Change: Text-based report → Map-based visual forecast.

Tech: Vanilla JS, Leaflet.js

핵심 가설 검증

문제: 텍스트 예보는 공간적 맥락이 부족.
해결: 지도 기반 시각화가 더 효과적일 것이라는 핵심 가설을 검증하기 위해, 간단한 부채꼴 차트 형태의 MVP를 구축.

ver.02: Enhancing Visual Realism

Problem: Based on initial user feedback, the fan-chart was too abstract for precise on-site analysis.
Action: Replaced it with a grid-based heatmap using interpolation, significantly improving visual realism and optimizing the UX for mobile.

Change: Abstract fan-chart → Granular grid heatmap.

Tech: Client-side Interpolation, Responsive CSS

시각적 현실감 강화

문제: 초기 사용자 테스트 결과, 부채꼴 차트가 현장 분석에 활용하기에는 너무 추상적이라는 피드백을 받음.
해결: 시각적 현실감을 높이기 위해 보간법을 적용한 그리드 기반 히트맵으로 교체하고, 모바일 UX를 최적화.

ver.03: Upgrading the Prediction Engine

Problem: A static model could not adapt to changing weather.
Action: Upgraded the prediction engine with a dynamic weighting system, achieving a stable cosine similarity of 0.5875, meaning our lightweight model's directional predictions now closely matched the complex RandomForest model's output without the heavy computational cost.

Change: Static prediction model → Adaptive engine with dynamic weighting.

Tech: Python, Scikit-learn (RandomForest), SHAP

예측 엔진의 지능화

문제: 고정된 모델은 변화하는 기상에 적응 불가.
해결: RandomForest 모델로 안정적인 코사인 유사도 0.5875를 달성하는 동적 가중치 시스템을 도입, 무거운 RandomForest 모델의 예측 방향성과 거의 동일한 결과를(코사인 유사도 0.5875) 훨씬 가볍게 구현하여 상황 적응적 정확도를 향상.

ver.04: Ensuring Operational Reliability

Problem: Disjointed information and UI bugs were hindering quick decision-making.
Action: Overhauled the UI, integrating all data into a stable, single-view dashboard and eliminating 100% of critical layout bugs to reduce cognitive load and cut decision-making time.

Change: Disjointed UI → Stable, single-view dashboard.

Tech: Flexbox, Advanced CSS, DOM Manipulation

운영 신뢰성 확보

문제: 분산된 정보와 UI 버그가 빠른 의사결정을 저해.
해결: 모든 데이터를 안정적인 단일 대시보드에 통합하는 UI 개편을 통해 치명적 레이아웃 버그를 100% 해결, 사용자의 인지 부하를 줄이고 의사결정 시간을 단축하여 운영 신뢰성을 확보.

ver.05: Providing Decision Confidence

Problem: Users needed to know not just the prediction, but how much to trust it.
Action: Introduced a visualized uncertainty score (±%) for each of the 8 directions, evolving the tool into a quantifiable decision-support instrument.

Change: Forecast-only output → Forecast + Quantified Uncertainty.

Tech: Client-side Dynamic Calculations

의사결정의 확신 제공

문제: 사용자는 예측뿐 아니라 그 신뢰도까지 파악해야 할 필요.
해결: 8개 방향별 불확실성(±%) 점수를 시각화하여, 예보 도구를 정량적 의사결정 지원 도구로 발전시킴.
