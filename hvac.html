LG HVAC Virtual Experience

← Back to Portfolio

Problem

Amidst the COVID-19 pandemic, the challenge was to create a virtual showroom for a core B2B product to secure client leads. The primary goal was 'generating leads by ensuring users complete the virtual tour,' but we faced technical limitations with 3D assets and the difficulty of conveying a complex product structure in a mobile-first environment.

Pain Point

Post-launch, GA4 analysis revealed a critical issue: an 80% bounce rate and a dismal 'virtual showroom completion rate,' our key performance indicator (KPI). This not only meant failing to secure leads but also risking a negative brand experience and threatening the entire project's ROI. A data-driven diagnosis to find the root cause of the low completion rate was imperative.

Action

Led a structured, hypothesis-driven project to improve the showroom completion rate, focusing on 'Usability,' 'User Experience (UX),' and 'Content'.

  • Hypothesis 1 (Usability): 'It's difficult to use.'
    → Implementation of an interactive tutorial based on competitor UX benchmarking to reduce the initial learning curve.
  • Hypothesis 2 (User Experience): 'The experience is poor.'
    → Pinpointed drop-off points using GA4, then visualized clickstream data as a heatmap using Python (Matplotlib, Seaborn). Identified a key bottleneck preventing completion: high-resource 3D assets in low-traffic areas slowing load times. Collaboration with engineers to optimize these assets using the LOD (Level of Detail) technique.

    • Figure 01: Heatmap of raw clickstream data identifying the UX bottleneck

  • Hypothesis 3 (Content): 'It's hard to find desired information.'
    → Redesigning the Information Architecture (IA) to a card-style format, arranging custom information based on user interests and actual exploration flows.

Result

  • Achieved a 25% increase in the core showroom completion rate.
  • 15 percentage point (p.p.) reduction in core bounce rate through comprehensive improvements.
  • 20% improvement in average page load speed via 3D asset optimization.
  • Direct contribution to securing B2B client leads by boosting user retention and completion.

Tech Stack

  • Google Analytics (GA4): Defining and tracking KPIs, including user funnels and showroom completion rate; extracting raw data for analysis
  • Python (Matplotlib, Seaborn): Leading data analysis; processing and visualizing raw clickstream data to identify problems and provide evidence for technical improvements
  • Information Architecture: Leading the redesign of the content structure to improve user engagement and journey completion

문제 정의 (Problem)

코로나19로 인해 오프라인 행사가 불가능해지면서, LG디스플레이의 핵심 B2B 제품인 HVAC 시스템을 소개할 가상 쇼룸을 구축하고, 이를 통해 잠재 고객 리드를 확보해야 하는 과제가 있었습니다. 목표는 '긍정적인 고객 경험을 통한 쇼룸 완주 및 리드 확보'였지만, 현실은 3D 에셋의 기술적 제약과 복잡한 제품 구조를 모바일 환경에서 효과적으로 전달해야 하는' 공간 기획의 어려움이었습니다.

페인포인트 (Pain Point)

런칭 직후, 80% 이상의 높은 이탈률과 함께 핵심 성공 지표(KPI)인 ‘가상 쇼룸 완주율’의 심각한 저조를 확인. 이는 리드 확보 실패를 넘어, 프로젝트 ROI를 위협하고 브랜드 경험에 부정적 영향을 줄 수 있는 결정적 문제. '왜 사용자가 완주하지 않는가?'에 대한 데이터 기반의 원인 규명 시급.

나의 기여 (Action)

'쇼룸 완주율' 개선을 목표로, '사용성', '경험(UX)', '콘텐츠' 측면에서 가설을 수립하고 데이터 기반으로 검증하는 구조적 개선 프로젝트 리드.

  • 가설 1 (사용성): '이용이 어렵다'
    → 경쟁사 UX 벤치마킹 및 초기 학습 부담을 줄이는 인터랙티브 튜토리얼 기획·도입.
  • 가설 2 (사용 경험): '사용 경험이 안 좋다'
    → GA4를 활용해 이탈 지점을 특정하고 Python(Matplotlib, Seaborn) 기반 클릭 스트림 데이터 히트맵 시각화. 완주를 저해하는 UX 병목 구간(저빈도 고용량 3D 에셋) 특정. 데이터 근거로 엔지니어와 협업하여 LOD(Level of Detail) 기법 최적화 진행.

    • Figure 01: 원시 클릭 스트림 데이터 히트맵 분석으로 UX 병목 구간 특정

  • 가설 3 (콘텐츠): '원하는 정보를 찾기 어렵다'
    → 고객의 관심사와 실제 탐색 흐름에 맞춰 카드형 콘텐츠 구성 및 맞춤형 정보 배치 방식으로 정보 구조(IA) 재설계.

성과 및 임팩트 (Result)

  • 핵심 경험 완주율 25% 증대 달성.
  • 종합적 개선을 통한 핵심 이탈률 15%p 감소.
  • 3D 에셋 최적화를 통한 평균 로딩 속도 20% 개선.
  • 사용자 리텐션 및 완주율 증대를 통한 B2B 고객 리드 확보에 직접 기여.

기술 스택(Tech Stack)

  • Google Analytics (GA4): 핵심 KPI(퍼널, 쇼룸 완주율) 정의 및 트래킹, 분석용 원시 데이터 추출
  • Python (Matplotlib, Seaborn): 데이터 분석 리드, 원시 데이터 가공 및 시각화로 문제 원인 규명 및 개선 근거 제시
  • Information Architecture: 사용자 여정 완주율을 높이기 위한 콘텐츠 구조 재설계 주도
